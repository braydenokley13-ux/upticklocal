Two files, built together:

**Uptick Local Site** — 12-section homepage plus all 11 interior pages (nav links switch pages), and a Mobile page with four phone screens and responsive rules. Three scroll-driven set pieces: the pinned hero where the 21″ screen cycles Host → Ad → Network → Action, the 540vh six-beat system story that builds additively, and the horizontal Beyond-the-Screen track. The audience+geography selector is live — click a network and a geography and the field re-routes. Motion annotations are on by default; turn them off in Tweaks.

**Uptick Local Design System** — all 25 parts, derived from the same direction: graphite + paper + signal amber, Familjen Grotesk / Archivo / Martian Mono, square corners with radius reserved for hardware, and the band-and-node motif as the ecosystem graphic. Tokens ship as CSS variables or JSON (Tweaks toggle).

Caveats: no invented numbers, coverage or testimonials anywhere; the geographies in the selector are labelled conceptual examples. All photography is honest hairline slots with written briefs. The device is a neutral mockup specced for one-place replacement with real product shots. Media-query-free responsiveness means the nav is designed for ≥1200px — the intended narrow behavior is drawn on the Mobile page rather than triggered by the browser.
